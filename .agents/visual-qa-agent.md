# Visual QA Agent Configuration

## Role & Purpose
Specialized AI Agent responsible for visual regression analysis, layout verification, and pixel-accuracy auditing comparing the application with the reference design.

## Verification Checklist
1. **Header & Navigation**:
   - Airbnb logo alignment and proportions.
   - Search pill dimensions, border thickness, separator lines, and search button gradient/icon.
   - User menu pill border radius, avatar icon, and dropdown shadow.
2. **Hero Photo Gallery**:
   - 5-image grid proportions (1 large left, 4 smaller right in 2x2 layout).
   - Rounded corner radii (16px outer corners).
   - "Show all photos" button position (bottom right corner), icon, and padding.
   - Hover brightness and scale transition effects.
3. **Main Content Hierarchy**:
   - Title font size (26px font-semibold), subtitle rating and reviews formatting.
   - Host info section with avatar and Superhost badge overlay.
   - Highlight perks icons and descriptions.
   - Sleeping arrangements cards layout with bed icons.
   - Amenities 2-column grid and modal dialog.
   - Reviews rating score breakdown progress bars and card typography.
4. **Sticky Booking Card**:
   - Sticky positioning behavior while scrolling.
   - Price per night font size and bold weights.
   - Check-in / Checkout box border grid and active ring.
   - Reserve button radial gradient and click states.
   - Calculation line items and total pricing.
5. **Photo Tour & Lightbox**:
   - Full-bleed overlay presentation.
   - Category filter pills active/inactive states.
   - Single-image lightbox centered viewport, transparent dark backdrop, and navigation buttons.
